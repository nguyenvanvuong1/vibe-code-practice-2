# Testing checklist
- [ ] Submit valid response -> localStorage tăng 1 record.
- [ ] Refresh -> record vẫn còn.
- [ ] Rating ngoài 1-5 bị chặn.
- [ ] NPS ngoài 0-10 bị chặn.
- [ ] Dashboard rỗng không NaN/Infinity.
- [ ] Average rating khớp phép tính tay trên 3 record test.
- [ ] NPS = %promoter(9-10) - %detractor(0-6).
- [ ] Comment chứa `<script>` chỉ hiển thị text, không thực thi.
- [ ] Clear yêu cầu confirm và xóa dữ liệu.
