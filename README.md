# AI Vibe Coding – Survey & Dashboard

Project thực hành giúp sinh viên dùng prompt để tạo một website survey + dashboard đơn giản bằng HTML/CSS/JavaScript, chạy trực tiếp trên browser và lưu dữ liệu bằng localStorage.

## Mục tiêu

- Biến yêu cầu nghiệp vụ thành prompt kỹ thuật rõ ràng.
- Prompt AI thiết kế survey, data schema, validation, dashboard.
- Hiểu luồng UI -> JavaScript -> localStorage -> aggregate -> visualization.
- Biết chia nhỏ prompt, kiểm thử output và cải tiến prompt.
- Hoàn thiện một mini product không cần backend/framework.

## Bắt đầu

1. Đọc `docs/student-guide.md`.
2. Làm theo `.github/instructions/vibe-workflow.instructions.md`.
3. Xem prompt mẫu trong `.github/prompts/` (chạy bằng `/tên-prompt` trong Copilot Chat) nhưng không copy nguyên văn.
4. Mở `sample-solution/index.html` để xem sản phẩm tham chiếu.
5. Làm các bài trong `docs/assignments/`.

Xem `docs/teacher-rubric.md` để biết tiêu chí chấm điểm, và `.github/copilot-instructions.md` cho các ràng buộc dự án mà AI coding agent sẽ tuân theo.

## Sản phẩm cuối khóa

Sinh viên xây một website gồm 2 màn hình:

- Survey: thu thập phản hồi khách hàng.
- Dashboard: KPI, phân bố rating, NPS, kênh tiếp cận, danh sách phản hồi.

Dữ liệu chỉ lưu trên trình duyệt bằng localStorage.
